# Talks written by agents

- The talk template ships an **AGENTS.md** describing the format.
- JSON Schemas (`schema/talk.schema.json`) give editor autocompletion via `$schema`.
- `wavesol check` is the feedback loop: precise `file:line:col` errors agents can fix.
