# Why a graph, not a list?

A linear deck forces one order on everyone. A fabric does not:

- **Detours.** A question about the lemma? Fly to it and back.
- **Questions.** Answer them in place by following an edge.
- **Returning.** The main line is just the chain of default edges — you always come back to it.

::: notes
The audience never loses the thread, because the camera, not a page number, defines position.
:::
