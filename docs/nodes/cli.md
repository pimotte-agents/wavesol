# The CLI

```sh
wavesol new my-talk   # create a talk from the template
wavesol dev           # live preview with reload; d: drag nodes to pin them
wavesol build         # static site in dist/ (any URL path); with pdf: also talk.pdf
wavesol serve         # build and serve locally to present from your laptop
wavesol check         # validate; errors as file:line:col; --render: what overflows
```

::: notes
build produces a fully static site — it works from any URL path, for example GitHub Pages.
:::
